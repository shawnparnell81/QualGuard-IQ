# QualGuard IQ website

Static marketing site. Plain HTML, CSS and a few lines of JavaScript for the mobile menu. No build step.

## Preview

Serve the folder with any static web server, for example:

    python3 -m http.server 8080 --directory site

## Before launch

- Replace `sales@example.com` in `index.html` with the real sales address.
- Replace the dashed placeholder boxes (customer logos, pricing, customer stories) once real content is approved.
- Photo sources and licences are listed in `CREDITS.md`.

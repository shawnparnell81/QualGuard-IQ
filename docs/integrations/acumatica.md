# Acumatica connector research (contract-based REST)

- Auth: OAuth 2.0/OIDC. Register the client in **Connected Applications (SM303010)**, pick the flow (Authorization Code, Implicit, Resource Owner Password Credentials, Hybrid), add a shared secret, and request scope `api` (+`offline_access` for refresh). HTTPS is required. https://beacon.acumatica.com/r/Form-Reference-Guide/Integration-Forms/Connected-Applications, https://help.acumatica.com/Wiki/ShowWiki.aspx?PageID=c6294b6b-a460-491e-8130-ae55d063c15c&wikiname=HelpRoot_Dev_Integration
- **Gotcha:** there's no client-credentials grant in the flow list, so server-to-server uses Resource Owner Password with a dedicated integration user (restricted roles). Token: `POST https://<host>/<instance>/identity/connect/token`. https://help.acumatica.com/Wiki/ShowWiki.aspx?pageid=638b2743-8ca8-49a8-96d5-e2f0601b0827. Cookie login (`/entity/auth/login`) also exists (**UNVERIFIED**) and consumes an API session, so prefer OAuth.
- Connected apps must be added to a customization project to move to other instances (same general info page).
- Base: `https://<host>/<instance>/entity/Default/<version>/<Entity>`, e.g. `/entity/Default/25.200.001/SalesOrder/SO/000001`, header `Authorization: Bearer`. https://help.acumatica.com/(W(8))/Wiki/ShowWiki.aspx?pageid=ed9fe5ab-b3c0-444c-8335-ff3b0c8392d6
- Entities (Default endpoint): `StockItem`, `Customer`, `Vendor`, `Employee`, `PurchaseOrder`, `PurchaseReceipt`, `WorkCenter`/`ProductionOrder`/`BillOfMaterial` (Manufacturing endpoint `MANUFACTURING/<ver>`), item revisions via Manufacturing BOM revisions, lots/serials via `InventoryLotSerialInquiry` or receipt line allocations: all **UNVERIFIED** names. Check `GET /entity/Default/<ver>/$adHocSchema` and the endpoint's Swagger at `/entity/Default/<ver>/swagger.json` (**UNVERIFIED**).
- Paging/filter: `$top`, `$skip`, `$filter=LastModifiedDateTime gt datetimeoffset'...'`, `$select`, `$expand`, `$custom` (**UNVERIFIED** cite).
- Limits: license restrictions on API users, concurrent requests and requests per minute (view in **License Monitoring Console SM604000**). Queued when concurrency is full; throttled after 50% of the per-minute limit; declined if the queue exceeds 20 or waits over 10 min. https://beacon.acumatica.com/r/Integration-Development-Guide/Limiting-Connections-of-Integrated-Applications/License-Restrictions-for-API-Sessions-and-Requests (exact thresholds **UNVERIFIED** beyond the search summary; re-read the page).
- Events: **Push Notifications (SM302000)** send JSON POSTs from GI or built-in queries to a destination URL, with retries. https://beacon.acumatica.com/r/Integration-Development-Guide/Configuring-Push-Notifications-for-Real-Time-Monitoring/Push-Notifications-General-Information, https://beacon.acumatica.com/r/Integration-Development-Guide/Configuring-Push-Notifications-for-Real-Time-Monitoring/Push-Notifications-Destinations
- Errors: JSON with `message`, `exceptionMessage`, plus per-field `error` on entity payload (**UNVERIFIED**).
- Sandbox: customer sandbox tenants via partner/SaaS (**UNVERIFIED**). Writes: read-only default.
